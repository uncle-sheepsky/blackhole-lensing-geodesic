# blackhole-lensing-geodesic

영상 「블랙홀은 어떻게 그리나요」(1080×1920 · 30.000초 · 750프레임 @25fps)를
**그린 코드 그대로**입니다. 영상에서 한 말이 이 코드에서 참인지 `verify.mjs` 가 검사합니다.

- 슈바르츠실트 시공간에서 **광자 측지선을 카메라에서 거꾸로 적분**하는 WebGL2 프래그먼트 셰이더
- 강착원반 · 도플러 빔잉 · 중력 감쇠 · 광자링 · **2차상**(적도면 다중 교차)
- 빨려드는 별 = 셰이더가 아니라 **속도 Verlet 사전 적분**(`infall_engine.js`)
- 라이선스 **CC0 1.0** (폰트는 각자의 OFL — `_fonts/` 참조)

## 5초 만에 보기 — 서버 필요 없음

`src/comp.html?preview` 를 브라우저로 그냥 엽니다. 아래 슬라이더로 아무 프레임이나 볼 수 있고,
←/→ 로 1프레임, Shift+←/→ 로 25프레임(=1초) 이동합니다.

## 코드가 영상의 주장을 검사한다

```bash
node verify.mjs        # src/ 안에서
```

| # | 검사 | 영상의 어느 주장인가 |
|---|---|---|
| 1 | 결정론 — 측지선·인폴 재실행 시 **비트 동일** | 「같은 프레임을 다시 그리면 같은 그림」 |
| 2 | 약장 편향각 → **4M/b** (2차항 15πM²/4b² 까지 대조) | 「지날 때마다 조금씩 꺾어 준다」 |
| 3 | 임계 임팩트 파라미터 → **3√3·M = 2.598 Rs** | 화면의 `b_crit = 2.598 Rs` |
| 4 | 적도면 **2회 통과** 광선이 실재 · 전부 그림자 아래 초승달 | 「뒤에 있던 원반이 위아래로 감겨 보입니다」 |
| 5 | 도플러 빔잉 — 다가오는 쪽이 밝다 | 화면의 `다가옴 ×1.75 / 멀어짐 ×0.56` |
| 6 | 인폴 Verlet — 항력 0 이면 각운동량 보존, 항력 有면 반경 감소 | 「셰이더가 아니라 중력을 미리 적분해 둔 값」 |

## 프레임을 직접 굽기

```bash
npm i playwright && npx playwright install chromium
node render.mjs              # 결정론 게이트(역순 재시크 픽셀 SHA) + G7
node render.mjs --all        # 750프레임 → frames/
node render.mjs --contact    # 12 컴프 컨택트 시트
node hold_gate.mjs           # G6 컴프 유지 시간
```

⚠**`DET_SW=0` 을 주면 GPU 로 돕니다(≈25배 빠름). 대신 결정론이 깨집니다** —
실 GPU(ANGLE/D3D11)에서 같은 프레임을 정순·역순에 찍으면 max Δ4~8/255 가 수백 픽셀에
흩어져 나왔습니다. 납품본과 게이트는 SwiftShader(기본값)로 돌립니다.

## 파일

| | |
|---|---|
| `src/lens_engine.js` | 렌징 셰이더(WebGL2) + 카메라·투영. **영상 C9 에 이 파일의 107~118줄이 그대로 뜹니다** |
| `src/geodesic.js` | 같은 적분식의 JS 판본(화면에 광선 경로를 그리고 verify 가 검사) |
| `src/infall_engine.js` | 별 인폴 — 속도 Verlet + 반경 의존 항력 |
| `src/beats4.js` | 연출 정본 — 12 컴프 표 · 시선 진입/종점 · 카메라 |
| `src/comp.html` | 컴포지터. `__seekTo(t)` 단일 진입 · `?preview` 로 슬라이더 |
| `src/code_data.js` | 자동 생성 — 화면에 띄우는 코드 발췌(원문 줄·줄번호·SRC_SHA) |
| `src/render.mjs` · `src/browser.mjs` | 결정론 렌더 + 게이트 |
| `src/verify.mjs` | 위 6종 검사 |
| `src/hold_gate.mjs` | 컴프 유지 시간(G6) |
| `_fonts/` | Pretendard · JetBrains Mono (각 OFL 동봉) |

## 안 들어 있는 것

나레이션 음성·BGM·완성 mp4 는 포함하지 않습니다(각각 본인 음성 학습 TTS 와 자작 신스 산출물).
`render.mjs --all` 로 나오는 것은 **무음 프레임 시퀀스**입니다.
